# Migration Documentation

This directory keeps the migration notes and phase archives out of the project
root.

## Layout

- `phases/`
  - detailed phase reports, for example `PHASE12.2_ALPHA_RELEASE_CHECKLIST.md`.
- `release/`
  - release-facing notes, for example
    `RELEASE_NOTES_7.0.0-alpha.1-mc26.1.md`.
- `artifacts/`
  - local phase logs, diffs, screenshots, command probes and duplicate scratch
    files when they need to be kept temporarily.

The root-level `MIGRATION_PLAN_26.1.md` remains the active chronological plan.
